# Projeto Git - Comparação de Números

## Descrição
Projeto desenvolvido em Python para comparar dois números e verificar se são iguais ou diferentes.

## Instruções
1. Abrir o ficheiro programa.py no VS Code.
2. Executar o programa com Python.
3. Introduzir dois números inteiros.
4. Verificar o resultado apresentado.

## Tecnologias
- Python
- Git
- GitHub
- Visual Studio Code
